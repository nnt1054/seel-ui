### withActiveNode

HOC Decorator for instantiating and creating custom active node components.

Using the decorator will make the wrapped component:

- register itself onto its parent childrenRef
- set up and provide its ActiveNodeContext which enables the usage of the `useActiveNode` hook in the component.

Every node has their own zustand store initialized and stored within the ActiveNodeContext; the zustand store holds all the relevant properties for managing and moving focus within a parent as well as among a node's children nodes.

### Usage Guidelines

- `withActiveNode` requires all components to support a `ref` and `node` prop, where the ref is required to be set to a DOM element. It will also provide a default value for the `ref` prop, so when instantiating an active node component, it's not required to manually generate a new ref for each one.
- `withActiveNode` has an additional boolean arg `ignoreParent` for creating node components within a node that want to break from the normal hierarchy. This is primarily used with popover/dialog/dropdown components that are expected to receive events directly using the `inputInFocus` utility.

### Examples

```jsx
const CustomComponent = withActiveNode((props) => {
  const { ref, node, ...elementProps } = props;

  const { hasFocus } = useActiveNode();

  return (
    <div ref={ref} data-focused={hasFocus ? "" : null} {...elementProps} />
  );
});
```
