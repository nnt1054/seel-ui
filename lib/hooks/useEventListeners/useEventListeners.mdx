<Subtitle>Hook for setting up multiple event listeners and their callbacks.</Subtitle>

### Usage Guidelines
* `useEventListeners` can also be used to setup event listeners for regular events such as "click", "change", "mousedown", etc.
* Listeners can be toggled on and off using the `isActive` argument.

### Examples

#### Custom Component with Event Listeners Hook

```jsx
const CustomComponent = withActiveNode((props) => {
	const {
		ref,
	} = props;

	const [isActive, setIsActive] = useState(true);

 	const { grabFocus } = useActiveNode();

	const callbacks = useEventListeners(ref, {
		confirm: () => { grabFocus() },
		toggle: () => { setIsActive(!isActive) },
		foo: () => { console.log('foo') },
		bar: () => { console.log('bar') },
	}, isActive);

	return (
		<div onClick={ callbacks.confirm } />
	)
})
```
