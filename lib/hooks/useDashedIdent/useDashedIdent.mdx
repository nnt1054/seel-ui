<Subtitle>Hook for creating dashed identifiers to use as anchor names.</Subtitle>

### Usage Guidelines
* Primarily used to generate anchorNames for use with popover CSS stylings.

### Examples

#### Custom Component with Adjacent Nodes Hook

```jsx
const App = () => {
	const ref = useRef();

	const anchorName = useDashedIdent();

	const [isOpen, setIsOpen] = useState(false);
	const toggle = () => setIsOpen(!isOpen);

	return (
		<InputProvider inputRef={ ref }>
			<Button
				ref={ ref }
				onClick={ toggle }
				style={{ anchorName, }}
			> toggle </Button>

			<Modal
				node={ 'modal' }
				hasFocus={ isOpen }
				initial={ 'list' }
				anchorName={ anchorName }
				isOpen={ isOpen }
				setIsOpen={ setIsOpen }
			/>
		</InputProvider>
	)
}
```
