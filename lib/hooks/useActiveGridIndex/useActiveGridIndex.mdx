<Subtitle>Hook for moving and controlling an focus across a 2-dimensional grid of ordered integer nodes.</Subtitle>

### Usage Guidelines

* All child nodes must have integer node names in sequential order from 0 (inclusive) to `maxIndex` (exclusive).

### Examples

#### Custom Component with Active Grid Index Hook

```jsx
const CustomComponent = withActiveNode((props) => {
	const {
		ref,
		node,
		adjacentNodes = {},
		columns = 1,
		maxIndex = 1,
		initialIndex = 0,
		...others
	} = props;

	const {
		moveFocus,
		activeNode: activeIndex,
		setActiveNode: setActiveIndex,
	} = useActiveNode();

	useActiveGridIndex({
		ref,
		activeIndex,
		setActiveIndex,
		columns,
		maxIndex,
		initialIndex,
		adjacentNodes,
		moveFocus,
	});

	return (
		<div ref={ ref } {...others } />
	)
})
```
