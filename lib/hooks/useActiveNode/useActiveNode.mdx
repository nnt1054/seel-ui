<Subtitle>Hook for retrieving Active Node Properties and Methods.</Subtitle>

Hook that provides the primary properties and function methods for controlling focus within the Active Node System.  The properties are split into two categories that either deal with the current node as a child within a parent or as a parent with a set of chidren.  The functions provided are intended to directly be used with other hooks within the `seel-ui` library.

### Usage Guidelines

* Using `useActiveNode` will set up hooks into the active node properties so components will be expected to rerender when their focus or activeNode values are updated.
* The `hasFocus` property is also dependent on having both the current node being the activeNode within its parent as well as the parent being the `activeNode` within the grand-parent (with the exception of if the `hasFocus` prop is populated).
* In order to retrieve properties/methods without hooking into it/causing rerenders, it is possible to retrieve the underlying zustand store using the `ActiveNodeContext` and the `store.getState()` method.

### Examples

#### Custom Component with Active Node Hook

```jsx
const CustomComponent = withActiveNode((props) => {
  const { ref } = props;

  const {
    hasFocus,
    moveFocus,
    grabFocus,
    childrenRef,
    activeNode,
    setActiveNode,
  } = useActiveNode();

  return <div ref={ref} />
});
```
