<Subtitle>A scrollable container for holding content.</Subtitle>

A container element that renders either a scrollable `div` element.  ActiveScrollableNode's listen for directional navigation events and scrolls itself in the appropriate direction.  When the maximum or mininum scroll position is reached, focus will be passed to the adjacent node in the current direction if any.

### Usage Guidelines
* ActiveScrollableNode as it is is not meant to render and hold other active nodes or interactable elements and is meant to render plain display only html or react components.
* To add additional behaviors and functionality, it's encouraged to create your own custom components while making use of the `useActiveScrollableNode` hook to replicate the scrolling functionality.

### Anatomy

```jsx
import { ActiveScrollableNode } from 'seel-ui';

<ActiveScrollableNode />
```

### Examples

#### Active Scrollable Node with an adjacent Button list

```jsx
const App = () => {
	const ref = useRef();

	return (
		<InputProvider inputRef={ ref }>
			<ActiveContainer
				ref={ ref }
				hasFocus={ true }
				initial={ 'content' }
			>
				<ActiveScrollableNode
					node={ 'content' }
					adjacentNodes={{
						down: 'actions',
					}}
				>
					Lorem ipsum dolor sit amet.
					Ut autem dolores et quasi itaque ut molestiae ipsum.
					Est quaerat aliquam id sapiente ullam non dolores odio.
					...
				</ActiveScrollableNode>
				<ActiveList
					node={ 'actions' }
					adjacentNodes={{
						up: 'content',
					}}
					orientation={ 'horizontal' }
				>
					<ActiveList.Item node={ 0 }> Back </ActiveList.Item>
					<ActiveList.Item node={ 1 }> Accept </ActiveList.Item>
				</ActiveList>
			</ActiveContainer>
		</InputProvider>
	)
}
```
