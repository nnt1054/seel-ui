<Subtitle>A container element for rendering and cycling between multiple panels.</Subtitle>

A container that renders a `div` element and can cycle between rendering one panel from an ordered series of child panel components.  Tabs will also render a list of buttons for swapping between the different panels as well as listens for `cycleL` and `cycleR` to cycle through the available options.

### Usage Guidelines
* `Tabs.Panel` components are expected to only have one direct child descendent which is an Active Node and accepts a `node` and `adjacentNodes` prop.  Additionally, nodes within a Panel will automaticaly have their `node` prop populated to `content` and their `adjacentNodes` prop derived using the `listPositions` and `adjacnetNodes` property from the `TabsContext`.
* The `Tabs.List` is a wrapper over the `ActiveList` component.  It will largely have the same API with the exception that its `adjacentNodes` prop will be automaticaly populated based on its relative position to the content.
* The `Tabs.CycleButton` renders a plain `button` component and is not an actual active node; so it will have a clickable behavior but cannot be navigated to by normal means.

### Anatomy

```jsx
import { Tabs } from 'seel-ui';

<Tabs>
	<Tabs.List>
		<Tabs.CycleButton />
		<Tabs.Tab />
	</Tabs.List>

	<Tabs.Panel />
</Tabs>
```

### Examples

#### Tabs with 3 Different Panels

```jsx
const App = () => {
	const ref = useRef();

	return (
		<InputProvider inputRef={ ref }>
			<Tabs
				ref={ ref }
				hasFocus={ true }
				initial={ 1 }
				maxIndex={ 3 }
			>
				<Tabs.List>
					<Tabs.CycleButton direction={ 'left' }> L </Tabs.CycleButton>
					<Tabs.Tab node={ 0 }> Tab w/ Text </Tabs.Tab>
					<Tabs.Tab node={ 1 }> Tab w/ Buttons  </Tabs.Tab>
					<Tabs.Tab node={ 2 }> Tab w/ Grid </Tabs.Tab>
					<Tabs.CycleButton direction={ 'right' }> R </Tabs.CycleButton>
				</Tabs.List>

				<Tabs.Panel index={ 0 }>
					<ActiveScrollableNode>
						Lorem ipsum dolor sit amet.
						Ut autem dolores et quasi itaque ut molestiae ipsum.
						Est quaerat aliquam id sapiente ullam non dolores odio.
						...
					</ActiveScrollableNode>
				</Tabs.Panel>

				<Tabs.Panel index={ 1 }>
					<ActiveList>
						<ActiveList.Item node={ 0 }> Item 0 </ActiveList.Item>
						<ActiveList.Item node={ 1 }> Item 1 </ActiveList.Item>
						<ActiveList.Item node={ 2 }> Item 2 </ActiveList.Item>
					</ActiveList>
				</Tabs.Panel>

				<Tabs.Panel index={ 2 }>
					<ActiveGrid columns={ 2 }>
						<ActiveList.Item node={ 0 }> Item 0 </ActiveList.Item>
						<ActiveList.Item node={ 1 }> Item 1 </ActiveList.Item>
						<ActiveList.Item node={ 2 }> Item 2 </ActiveList.Item>
						<ActiveList.Item node={ 3 }> Item 3 </ActiveList.Item>
					</ActiveGrid>
				</Tabs.Panel>
			</Tabs>
		</InputProvider>
	)
}
```

#### TabsContext

Note that the `TabsContext` react context object only stores a zustand store as its value.  The following table describes the properties of the held zustand store and can be accessed using `store.getState()` or hooked into via zustand's `useStore` function.

<Table
	headers={['Property', 'Description']}
	rows={[
		[<b>activeIndex</b>, "Index corresponding to the `node` of the current active tab panel of the component."],
		[<b>setActiveIndex</b>, "Function for setting the `activeIndex`."],
		[<b>maxIndex</b>, "Max integer value (exclusive) for `activeIndex`.  Also corresponds to the number of tabs in the component."],
		[<b>setMaxIndex</b>, "Function for setting the maxIndex.  Automatically is called when the `maxIndex` prop in updated."],
		[<b>listPositions</b>, "Object denoting the relative positions of TabsList components relative to the `content`/panel area of the Tabs component.  Object is used alongside the `adjacentNodes` property to calculate `adjacentNodes` object properties for sub-components."],
