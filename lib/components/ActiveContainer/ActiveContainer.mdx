<Subtitle>A basic container for holding active nodes.</Subtitle>

The most basic container element that renders an unstyled `div` element.  Its primary behavior is to listen for events and propagate them down to whichever of its direct child nodes is currently active.

### Usage Guidelines
* Moving focus between different children will/should be handled by the children nodes themselves via `adjacentNode` props and hooks that utilize them (Unlike `ActiveList`'s which manages its own focus between its children).
* Recommended to manually control and set the `hasFocus` prop if container is the top level node with no parent.

### Anatomy

```jsx
import { ActiveContainer } from 'seel-ui';

<ActiveContainer />
```

### Examples

#### Active Container with 2 Buttons

```jsx
const App = () => {
	const ref = useRef();

	return (
		<InputProvider inputRef={ ref }>
			<ActiveContainer
				ref={ ref }
				hasFocus={ true }
				initial={ 'foo' }
			>
				<Button
					node={ 'foo' }
					adjacentNodes={{ right: 'bar' }}
					onClick={() => { console.log('foo') }}
				> foo </Button>
				<Button
					node={ 'bar' }
					adjacentNodes={{ left: 'foo' }}
					onClick={() => { console.log('bar') }}
				> bar </Button>
			</ActiveContainer>
		</InputProvider>
	)
}
```
