<Subtitle>A basic number input.</Subtitle>

A basic number input component that renders an unstyled `input` element with type `number`.  Dispatching `confirm` and `cancel` events can be used to toggle or remove actual keyboard focus on the number input.

### Usage Guidelines
* `NumberInput` does not support an `adjacentNodes` prop; to replicate this logic it's recommended to wrap this input in something like an `ActiveList.item` component or another container node that supports `adjacentNodes` logic that will propagate `confirm`/`cancel` events appropriately.  This is due to expected directional navigation behavior being different depending on if the component has keyboard focus or not.
* As `NumberInput` renders an actual `input` element and passes through the remaining props to it, this node can be styled using most styling libraries and methods including CSS-in-JS, CSS modules and tailwind.  In-line styling is also possible with the caveat that it does not support data selectors at this time.

### Anatomy

```jsx
import { NumberInput } from 'seel-ui';

<NumberInput />
```

### Examples

#### Active List with 2 Number Inputs

```jsx
const App = () => {
	const ref = useRef();

	return (
		<InputProvider inputRef={ ref }>
			<ActiveList
				ref={ ref }
				hasFocus={ true }
			>
				<div>
					<span> Input 1: </span>
					<NumberInput node={ 0 }/>
				</div>
				<div>
					<span> Input 2: </span>
					<NumberInput node={ 1 }/>
				</div>
			</ActiveContainer>
		</InputProvider>
	)
}

```
