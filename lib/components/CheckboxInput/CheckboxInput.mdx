<Subtitle>A basic boolean input that toggles itself on a `confirm` event.</Subtitle>

A basic boolean input component that renders an unstyled `input` element with type `checkbox`.  It's onClick callback function is also called upon receiving a `confirm` event.  Supports an `adjacentNode` prop for passing focus to other nodes.

### Usage Guidelines
* As `CheckboxInput` renders an actual `input` element and passes through the remaining props to it, this node can be styled using most styling libraries and methods including CSS-in-JS, CSS modules and tailwind.  In-line styling is also possible with the caveat that it does not support data selectors at this time.
* `CheckboxInput` is intended to be used as a controlled input and must have a `value` + `setValue` pair passed into the props.
* If you're looking to create a custom toggle component instead of a checkbox, it is recommended to create a new component from scratch using the CheckboxInput source code as a starting point.

### Anatomy

```jsx
import { CheckboxInput } from 'seel-ui';

<CheckboxInput />
```

### Examples

#### Active Container with 2 Checkbox Toggles

```jsx
const App = () => {
	const ref = useRef();

	return (
		<InputProvider inputRef={ ref }>
			<ActiveContainer
				ref={ ref }
				hasFocus={ true }
				initial={ 'foo' }
			>
        <div>
          <span> Toggle 1: </span>
          <CheckboxInput
  					node={ 'foo' }
  					adjacentNodes={{ down: 'bar' }}
  				> foo </CheckboxInput>
        </div>
        <div>
        <span> Toggle 2: </span>
          <CheckboxInput
  					node={ 'bar' }
  					adjacentNodes={{ up: 'foo' }}
  				> bar </CheckboxInput>
        </div>
			</ActiveContainer>
		</InputProvider>
	)
}
```
