<Subtitle>A container for holding an ordered list of active nodes.</Subtitle>

The container element that renders either a horizontal or vertical flex `div` element.  ActiveList's listens for directional navigation events and handles moving focus within its own children.  Propagates all other events to it's children otherwise.

### Usage Guidelines
* You're able to style the provided `ActiveList.Item` directly but you can also put any other active node component inside; additionally not all components within the list need to be same.
* All items within the list must have an incrementing integer `node` name; and components with non-integer nodes should not be included as a direct child to the active list.
* In the edge case where there is a left adjacent node to a vertical active list and its child node with focus has a `left` event handler, on receiving a `left` event, both the event will still propagate and focus will be moved to the left adjacent node; which is likely not desirable so it's advised not to structure your components in this way.  This applies vice versa for `right` events and `up`/`down` events for horizontal lists.

### Anatomy

```jsx
import { ActiveList } from 'seel-ui';

<ActiveList>
	<ActiveList.Item />
</ActiveList>
```

### Examples

#### Active List with 4 Buttons

```jsx
const App = () => {
	const ref = useRef();

  const items = [
    { label: 'Button 0', onConfirm: () => { console.log('Button 0') } },
    { label: 'Button 1', onConfirm: () => { console.log('Button 1') } },
    { label: 'Button 2', onConfirm: () => { console.log('Button 2') } },    
  ];

	return (
		<InputProvider inputRef={ ref }>
			<ActiveContainer
				ref={ ref }
				hasFocus={ true }
				initial={ 'foo' }
			>
				<ActiveList
					node={ 'foo' }
					maxIndex={ 4 }
					initialIndex={ 0 }
					orientation={ 'vertical' }
					disableWrap={ false }
					disableJump={ false }
				>
					{
						items.map((item, i) => {
							return (
								<ActiveList.Item
									key={ i }
									node={ i }
									onConfirm={ item.onConfirm }
								> { item.label } </ActiveList.Item>
							)
						})
					}
					<Button
						node={ 3 }
						onClick={() => { console.log('hello world') }}
					> Hello World </Button>
				</ActiveList>
			</ActiveContainer>
		</InputProvider>
	)
}
```
