<Subtitle>A container for rendering an ordered list of active nodes as a 2-dimensional grid.</Subtitle>

A container element that renders either a `div` element with display `grid` styling added to it.  ActiveGrid's listens for directional navigation events and handles moving focus within its own children.  Propagates all other events to its children otherwise.

### Usage Guidelines
* You're able to style the provided `ActiveGrid.Item` directly but you can also put any other active node component inside; additionally not all components within the list need to be same.
* All items within the grid must have an incrementing integer `node` name; and components with non-integer nodes should not be included as a direct child to the active list.

### Anatomy

```jsx
import { ActiveGrid } from 'seel-ui';

<ActiveGrid>
	<ActiveGrid.Item />
</ActiveGrid>
```

### Examples

#### Active Grid with 25 Buttons

```jsx
const App = () => {
	const ref = useRef();

	return (
		<InputProvider inputRef={ ref }>
			<ActiveContainer
				ref={ ref }
				hasFocus={ true }
				initial={ 'grid' }
			>
				<ActiveGrid
					node={ 'grid' }
					columns={ 5 }
					maxIndex={ 25 }
					initialIndex={ 0 }
				>
					{
						Array(25).fill(0).map((_, i) => {
							return (
								<ActiveGrid.Item
									key={ i }
									node={ i }
								>{ i }</ActiveGrid.Item>
							)
						})
					}
				</ActiveGrid>
			</ActiveContainer>
		</InputProvider>
	)
}
```
