<Subtitle>A popup container for rendering nodes on the top layer of a page.</Subtitle>

A container element that renders a `dialog` element with `manual` popover behavior.  Modal's will capture and trap focus while open but will otherwise behave similaraly to ActiveContainer's and propagate events to its children.

### Usage Guidelines
* Modals are deattached from the normal Active Node tree/hierarchy such that it won't have an active parent.  As such, it's necessary to populate the `hasFocus` prop similarly to any top level ActiveContainer/Node.  It's recommended to leverage the same value as `isOpen` in this case.
* While `isOpen` is `true`, the Modal will attempt to capture and trap the actual HTML/document `focus` by periodically checking and validating that `document.activeElement` references itself.
* In order to receive events from the InputManager, the InputManager commands must be configured to check for any focused `input` or `dialog` elements to dispatch to first before proceeding with the active node tree.  Examples of this can be found in the `getNavigationCommands` function using the `inputInFocus` util.
* Modal controls will be exposed in a zustand store made accessible via the `ModalContext` context object.  Components can access these functions as shown in the `ModalListItem` custom component in the example provided below.

### Anatomy

```jsx
import { Modal } from 'seel-ui';

<Modal />
```

### Examples

#### Dropdown Modal with 3 List Items

```jsx
const App = () => {
	const ref = useRef();

	const anchorName = useDashedIdent();

	const [isOpen, setIsOpen] = useState(false);
	const toggle = () => setIsOpen(!isOpen);

	return (
		<InputProvider inputRef={ ref }>

			<Button
				ref={ ref }
				onClick={ toggle }
				style={{ anchorName, }}
			> toggle </Button>

			<Modal
				node={ 'modal' }
				hasFocus={ isOpen }
				initial={ 'list' }
				anchorName={ anchorName }
				isOpen={ isOpen }
				setIsOpen={ setIsOpen }
			>
				<ActiveList node={ 'list' }>
					<ModalListItem node={ 0 }> Item { 0 } </ModalListItem>
					<ModalListItem node={ 1 }> Item { 1 } </ModalListItem>
					<ModalListItem node={ 2 }> Item { 2 } </ModalListItem>
				</ActiveList>
			</Modal>

		</InputProvider>
	)
}

export const ModalListItem = (props) => {
    const store = useContext(ModalContext);
    const onConfirm = () => {
        const { closeModal } = store.getState();
        closeModal();
    }

    return (
        <ActiveList.Item
            { ...props }
            onConfirm={ onConfirm }
        />
    )
}
```
