# Introduction to Seel UI

### What is Seel UI?

Seel UI is an unstyled UI component library/system for building out user interfaces with (hopefully) more intuitive navigation using directional input events from both a keyboard or gamepad.

### How does it work?

There are two main parts for making the system work; the Input Manager and the Active Node System. The Input Manager is in charge of listening to keyboard and Gamepad API events and execute actions based on a user provided keybind to command function mapping.  From there, the default commands will dispatch a set of events to the Active Node System through the DOM Events API.

#### Active Node System
The active node system provides a pattern for creating and designating dom elements and components as navigable or interactable elements within the user interface.  Through the Active Node API you're able to define adjacency between nodes for moving a virtual cursor/shifting focus based on directional input events; as well as establishing a node hierarchy for propogating input events down to any active child nodes.

the default set of hooks are used for composing active node behaviors (see the uhh composing nodes section)

all nodes can be nested inside a parent node and have a set of active nodes as children; among their child nodes at most one node will be designated as having "focus" or being "active" within their parent node and the node the bottom of the hierarchy is where the "virtual cursor" is considered to be.
